# 임신 확인 모드 기획

> 목적: 시술·자연임신 준비 사용자가 임신을 확인한 뒤에도 앱에 머물 이유를 만든다.
> 성공 사용자의 "졸업 이탈"을 막는 것이 아니라, 임신 초기 관리 → 출산 지원금 → 산전 검사까지 6~12개월을 자연스럽게 이어 주고, 연간 구독의 환불 리스크를 낮추는 것이 목표다.

## 1. 문제와 목표

| 문제 | 목표 |
|---|---|
| 판정 성공 즉시 구독 취소, 연간 결제자는 환불 요청 | 임신 후에도 쓰는 기능이 있음을 페이월·설정에서 보여 준다 |
| 시술 기록이 산부인과로 이어지지 않음 | 시술 기록 요약을 한 번에 공유(텍스트)할 수 있게 한다 |
| 출산 지원금(바우처·첫만남이용권·부모급여)을 사용자가 따로 찾아야 함 | 임신 모드 홈에서 금액·신청처·시점을 안내한다 |

성과 지표: 판정 단계 → 임신 모드 전환율, 임신 모드 진입 후 30일 유지율, 연간 구독 환불 요청 수.

## 2. 모드 정의

- 프로필 `treatmentStage = 'pregnant'` (백엔드 DTO·공유 타입에 이미 허용된 값).
- 새 프로필 필드
  - `pregnancyLmpDate` (YYYY-MM-DD): 임신 주수 계산 기준일. 마지막 생리 시작일(LMP) 또는 이식일에서 환산.
  - `pregnancyConfirmedAt` (YYYY-MM-DD): 임신 확인일(기록용).
- 이식 기준 환산: `LMP = 이식일 − (14 + 배아 배양 일수)`. 3일 배아면 −17일, 5일 배아면 −19일.
- 출산 예정일: `LMP + 280일`. 앱은 항상 "예정일은 의료진 확인 기준으로 조정될 수 있음"을 함께 표시한다.
- `currentMode(NATURAL|CLINIC)`는 바꾸지 않는다(커뮤니티 카테고리 정렬용). `currentStage`는 null 로 초기화.

## 3. 진입 경로

1. 설정 > 나의 치료 정보 > 현재 모드 > **"임신을 확인했어요"** → 기준일 입력 화면.
2. 홈: 시술 모드에서 현재 단계가 `result`(판정 대기)이면 "임신을 확인했다면 →" 카드 노출.
3. 기준일 입력 화면(`/pregnancy-setup`): LMP 직접 입력 또는 이식일+배아일수 → 주수·예정일 미리보기 → 저장.
4. 되돌리기: 설정에서 자연임신·시술 모드로 다시 변경 가능(기록 유지).

## 4. 화면별 변화 (treatmentStage == 'pregnant')

| 화면 | 변화 |
|---|---|
| 홈 히어로 | "임신 N주 M일", 출산 예정일 D-day, 분기(1·2·3) 배지, 주수별 짧은 안내, 다음 산전 검사 안내 |
| 홈 빠른 기록 | 체중 기록, 컨디션 메모 |
| 홈 오늘 할 일 | 엽산(~12주)·철분(16주~) 챙기기, 오늘 일정, 다음 검사 |
| 홈 지원금 카드 | 난임 지원금 카드 대신 **임신·출산 지원 카드** → `/birth-benefits` |
| 캘린더 요약 | 배란·생리 예측 대신 주수·예정일·다음 일정 |
| 캘린더 일정 종류 | 산전진찰 · 초음파 · 검사 · 기타 (배란·채취·이식 칩 숨김) |
| 캘린더 CTA | 일정이 없으면 "산전 검사 일정 한 번에 만들기"(회차 템플릿 재사용) |
| 기록 | 병원 수치·시술 지표 탭 숨김, 일반 기록은 체중·수면 중심 |
| 정보 탭 비용·지원 | 난임 지원금 대신 임신·출산 지원 요약 카드 우선 |
| 시술 기록 요약 | `/treatment-summary`: 회차별 완료 일정·약물·판정 기록을 텍스트로 정리해 공유 |

## 5. 산전 검사 템플릿 (예시 일정)

회차 템플릿과 같은 방식. 기준일 = LMP(환산). **모든 문구는 "일반적 권장 시기"이며 병원 일정에 맞춰 수정**하도록 안내한다. 약물·검사 항목 강제는 없다.

| 시기 | 단계 |
|---|---|
| 6~8주 | 초음파(태낭·심박 확인) |
| 10~13주 | 1차 기형아 선별(NT 초음파·혈액) |
| 16~18주 | 2차 기형아 선별(혈액) |
| 20~24주 | 정밀 초음파 |
| 24~28주 | 임신성 당뇨·빈혈 검사 |
| 28주 | 산전 진찰(Rh 음성 시 면역글로불린 상담) |
| 32~34주 | 초음파·태아 성장 확인 |
| 35~37주 | GBS 검사 |
| 36주~ | 주 1회 진찰 |

## 6. 임신·출산 지원 안내 (2025년 기준, 확인일 명시)

| 항목 | 금액 | 신청 |
|---|---|---|
| 임신·출산 진료비 바우처(국민행복카드) | 단태아 100만 원, 다태아 태아당 100만 원 | 카드사·정부24, 임신 확인 후 |
| 첫만남이용권 | 첫째 200만 원, 둘째 이상 300만 원 | 출생 후 행복출산 원스톱 |
| 부모급여 | 0세 월 100만 원, 1세 월 50만 원 | 출생 후 60일 이내 신청 시 출생월부터 |
| 보건소 철분제·엽산제 | 무료 | 관할 보건소 |
| 산모·신생아 건강관리 지원 | 소득 기준별 본인부담 차등 | 출산 예정 40일 전~출산 후 30일 |
| 지자체 출산장려금 | 지역별 상이 | 주민센터 |

금액은 앱 내 상수로 두되 `확인일`을 함께 표시하고, 지원금 규칙과 같은 Firestore config 이관을 후속 과제로 둔다.

## 7. 유료 경계

기존 게이트 유지: 일정 2건 이상(산전 템플릿 포함)·약물 알림·진행 관리 체크는 프리미엄. 임신 모드 자체는 무료. 페이월 문구에 "임신 후 산전 검사 일정·출산 지원 안내까지" 한 줄 추가.

## 8. 단계별 구현

1. 데이터: 프로필 필드 2개(백엔드 허용 목록·DTO·공유 타입·앱 모델), 주수 계산 도메인 + 테스트, 산전 템플릿(백엔드 기본값)
2. 전환 UI: 설정 모드 옵션, 기준일 입력 화면, 홈 판정 단계 카드
3. 화면 분기: 홈 히어로·빠른 기록·할 일·지원 카드, 캘린더 요약·칩·범례·CTA, 기록 탭
4. 출산 지원 안내 화면, 정보 탭 연결
5. 시술 기록 요약 공유 화면
6. 페이월 문구, README

## 9. 안전 원칙

- 주수·예정일·검사 시기는 참고용이며 진단이 아님을 모든 화면에 표기.
- 유산·사산 등 임신 종료 시 사용자가 스스로 모드를 바꾸며, 앱은 축하·격려 문구를 강요하지 않는다(모드 변경 화면에 중립 문구).
- 임신 모드 데이터도 민감정보. 배우자 공유 범위는 기존 시술 일정 공유와 동일하게 일정만.
