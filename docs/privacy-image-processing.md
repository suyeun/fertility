# 개인정보 처리방침 추가 문안 — 처방전·일정표 이미지 분석

> 처방표 스캔 기능 출시 전 개인정보 처리방침에 추가한다. 법률 자문 아님 — 시행 전 검토 필요.

## 처리 목적 및 항목
회사는 이용자가 직접 촬영·선택한 처방전 또는 주사 일정표 이미지를 **이용자의 요청 시에 한하여** 분석하여 약물 이름, 용량, 투약 날짜·시각, 병원 방문·검사 일정을 텍스트로 추출합니다. 추출 결과는 이용자가 확인·수정한 뒤 저장하기로 선택한 경우에만 이용자의 시술 일정으로 저장됩니다.

## 이미지의 보관
업로드된 이미지는 분석 처리 중에만 일시적으로 메모리에서 처리되며, 회사 서버·데이터베이스·로그에 저장하지 않습니다. 분석이 끝나면 즉시 파기됩니다. 앱은 분석 후 원본 이미지를 기기의 앱 저장 공간에 보관하지 않습니다.

## 처리 위탁
| 수탁자 | 위탁 업무 | 보유·이용 기간 |
|---|---|---|
| Anthropic, PBC (미국) | 이미지 내 텍스트·표 인식(AI 모델 API) | 처리 완료 즉시. 수탁자는 API 입력을 모델 학습에 사용하지 않으며, 자체 정책에 따른 단기 보관 후 삭제 |

국외 이전에 해당하므로 이전 국가(미국), 이전 일시·방법(분석 요청 시 암호화 전송), 이전받는 자의 연락처, 이전 항목(이미지)과 보유 기간을 함께 고지합니다.

## 이용자의 권리
이용자는 언제든 이 기능을 사용하지 않고 일정을 직접 입력할 수 있으며, 기능 사용이 다른 서비스 이용의 조건이 되지 않습니다.

## 카메라·사진 접근
카메라와 사진 보관함 접근은 이 기능을 실행할 때에만 이용자의 명시적 동의(운영체제 권한 요청)를 받아 이루어집니다.
