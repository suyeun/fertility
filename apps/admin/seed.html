👥 사용자 샘플 데이터 추가

20명의 샘플 사용자를 users 컬렉션에 추가합니다.
이미 동일한 ID가 존재하면 덮어씁니다. Flutter 앱에서 실제 가입한 사용자는 별도로 추가됩니다.

📝 콘텐츠 샘플 데이터 추가

9개의 샘플 콘텐츠(임신정보·건강팁·공지사항)를 contents 컬렉션에 추가합니다.

⚙️ 앱 설정 초기화

app_config 컬렉션에 iOS, Android 버전 정보와 서비스 공지 초기값을 설정합니다.

🚀 전체 초기화 (한 번에 실행)

위의 모든 작업을 순서대로 실행합니다. 처음 셋업 시 사용하세요.
